# BUY-UAT-01 — локальный buyer UAT checklist

**Среда:** integration branch `feat/horeca-unified-delivery-2026-11-24` @ `146a97e8304b016da5dfde9bcc1806d64f656a12`, feature-ветка `coder-a/buy-uat-01-2026-11-26`. Только локальный mocked Supabase build (`npm run e2e:ci`) и синтетические данные. Внешних участников, реальных заказов, оплат и уведомлений нет.

## Персоны и fixtures

- Покупатель-менеджер (`owner/admin/buyer`) с одной своей организацией и одной сохранённой точкой доставки.
- Синтетический одобренный поставщик с одним опубликованным оффером; черновые корзины «Select location» и «Fix quantity».
- Негативные варианты: пустой каталог (`offers: []`), изменённая версия оффера (`version: 2`), истёкшие/устаревшие условия (существующий forced stale-scenario), потерянный ответ при submit (существующий replay-scenario).

## Ограничения

Это локальный UAT на синтетических персонах, а не исследование с реальными покупателями. Не проверялись: реальная доступность, удобство для выбранного пилотного сегмента, иные браузеры/устройства, ручной screen-reader проход (A11Y-MANUAL-01), юридические и коммерческие ожидания. Результат не доказывает спрос или готовность к пилоту.
