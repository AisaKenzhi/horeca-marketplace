# Decision brief'ы по BLOCKED-задачам roadmap

**Назначение:** подготовить варианты и минимальные вопросы владельцу, чтобы снять блокеры. Здесь **нет выбранных политик** — агент не принимает юридических, коммерческих, операционных или продуктовых решений за владельца. После ответа владельца задача может быть повышена до `NEXT` и реализована в отдельном PR.

**База:** integration HEAD `87677790c70ec54cf1e9b51440dcd1123efd7817`. Уровень доказательств везде: local/ephemeral CI только; hosted/production не подключались.

## Что агент НЕ делает без отдельного решения

- Не выбирает юридического оператора, налоги, комиссию, валюту/FX, провайдера платежей или доставку.
- Не создаёт hosted/staging/production ресурсы, секреты и не применяет миграции к live БД.
- Не отправляет уведомления, не создаёт реальные заказы/резервы/платежи и не контактирует людей.
- Не превращает `submitted` в принятый заказ и не придумывает согласие из молчания.

Каждый ответ владельца должен называть task ID и конкретный выбор; после этого задача повышается до `NEXT`, получает отдельную ветку/PR и отметку `DONE` только после merge с зелёными required checks.
